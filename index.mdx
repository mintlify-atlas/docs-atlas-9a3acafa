ThingsBoard is an all-in-one open-source IoT platform that enables you to provision and manage devices, collect and visualize telemetry data, and automate responses with a visual rule engine. It supports MQTT, HTTP, CoAP, LwM2M, and SNMP protocols out of the box and scales from a single server to a full microservices deployment.

## Connect Devices in Minutes

ThingsBoard supports five transport protocols so you can connect virtually any device without gateways or adapters.

<Steps>
  <Step title="Create a device">
    Log in to the ThingsBoard UI, navigate to **Devices**, and create a new device. Copy the access token from the device credentials.
  </Step>
  <Step title="Push telemetry">
    Send a POST request (or MQTT publish) with your sensor data. ThingsBoard stores every data point with a server-side timestamp.

    ```bash
    curl -X POST https://your-host/api/v1/$ACCESS_TOKEN/telemetry \
      -H "Content-Type: application/json" \
      -d '{"temperature": 23.5, "humidity": 60}'
    ```
  </Step>
  <Step title="Build a dashboard">
    Open **Dashboards**, add widgets, and bind them to your device's telemetry keys. Your data appears in real time.
  </Step>
  <Step title="Add a rule chain">
    Create a rule chain to send an email or SMS alert when temperature exceeds a threshold — no code required.
  </Step>
</Steps>

## Supported Transport Protocols

<CardGroup cols={2}>
  <Card title="MQTT" icon="wifi" href="/connectivity/mqtt">
    Lightweight pub/sub protocol. Ideal for constrained devices. Supports QoS 0/1, persistent sessions, and TLS.
  </Card>
  <Card title="HTTP" icon="globe" href="/connectivity/http">
    Simple request/response over HTTPS. No client library needed — works from any language or shell script.
  </Card>
  <Card title="CoAP" icon="signal" href="/connectivity/coap">
    UDP-based protocol designed for low-power, lossy networks. Supports DTLS for secure communication.
  </Card>
  <Card title="LwM2M" icon="tower-broadcast" href="/connectivity/lwm2m">
    OMA LwM2M standard for cellular IoT devices. Supports bootstrapping, object model, and firmware updates.
  </Card>
</CardGroup>
